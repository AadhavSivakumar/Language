# Tamil teaching references

Source material for the vocabulary and sentences used in this app. These are
**reference PDFs** — downloaded from free / open / academic sources on
2026-07-20. Check each license before reusing content.

| File | Title | Source | License / terms |
|------|-------|--------|-----------------|
| `basic-tamil-msu.pdf` | *Basic Tamil* (239 pp.) — beginner textbook: alphabet, greetings, verbs, family, everyday conversation, worksheets | Michigan State University Open Books — https://openbooks.lib.msu.edu/basictamil/ | **CC BY-NC** (attribution, non-commercial) |
| `mcalpin-core-vocabulary-tamil.pdf` | *A Core Vocabulary for Tamil*, David W. McAlpin — frequency-based core word list | Digital South Asia Library, Univ. of Chicago — https://dsal.uchicago.edu/dictionaries/mcalpin/McAlpin_Tamil.pdf | Academic, free to access |
| `upenn-english-tamil-vocab.pdf` | English → Tamil basic vocabulary list | UPenn WALTT — https://ccat.sas.upenn.edu/plc/tamilweb/vocab/englishtamil.pdf | Academic, free to access |
| `upenn-tamil-english-vocab.pdf` | Tamil → English basic vocabulary list | UPenn WALTT — https://ccat.sas.upenn.edu/plc/tamilweb/vocab/tamilenglish.pdf | Academic, free to access |

## Notes

- *Basic Tamil* is **CC BY-NC**: fine for a free/non-commercial learning app with
  attribution; do **not** use it in a commercial product without checking terms.
- The McAlpin and UPenn PDFs are made freely available for study by their host
  institutions but are not explicitly open-licensed — treat as reference, not as
  content to redistribute wholesale.
- If this repository is or becomes **public**, consider adding `references/*.pdf`
  to `.gitignore` rather than committing the PDFs, to avoid redistributing them.

Deliberately **not** used: Scribd copies and "samacheerkalvi.guru"-style
aggregator mirrors of Tamil Nadu government textbooks — the textbooks themselves
are public, but those hosts are third parties with unclear rights. The official
government portal is https://www.textbooksonline.tn.nic.in if a Samacheer Kalvi
school textbook is wanted.
